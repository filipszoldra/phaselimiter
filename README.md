## Building

**Local build is not supported** — the engine requires Intel IPP (proprietary) and a specific
C++ toolchain. All builds run in GitHub Actions CI.

### CI: `build-engine` workflow

Triggered automatically on push to any `engine-*` branch, or manually via workflow dispatch.

Steps:
1. Checks out repo with all submodules
2. Installs Intel oneAPI IPP 2026 (cached between runs)
3. Installs oneTBB 2021+, Boost 1.82, Armadillo 12.6, libpng via conda-forge
4. Builds only the `phase_limiter` target (skips audio_analyzer, audio_visualizer, clear_mixer)
5. Uploads artifact `engine-bin` with `phase_limiter.exe` + all required runtime DLLs

To use: download the `engine-bin` artifact from a successful Actions run.

### Runtime dependencies (Windows, from artifact)

The artifact `engine-bin/bin/` contains everything needed:
- `phase_limiter.exe`
- `sndfile.dll` (prebuilt, in-tree)
- `tbb12.dll`, `tbbmalloc12.dll` (oneTBB from conda-forge)
- Boost DLLs: `boost_system`, `boost_filesystem`, `boost_serialization`, `boost_math_tr1`, `boost_iostreams`
- `libbz2.dll`, `zlib.dll`, `zstd.dll`

Also required at runtime (not in artifact):
- `ffmpeg.exe` on PATH or beside the executable
- `resource/` directory (sound_quality2_cache, mastering_reference.json, etc.) — taken from
  an upstream release, not regenerated by this build

## Build fixes vs upstream

The upstream code targets a discontinued Intel conda channel (HTTP 403) and the old TBB 2019
API. This fork applies the following fixes:

**CMakeLists.txt** — updated Windows IPP lib names (`ippimt.lib` → `ippi.lib` etc.),
added explicit `tbb.lib`/`tbbmalloc.lib` link, added `IPPROOT` include/link paths.

**GradCalculator.h** — removed `#include "tbb/pipeline.h"` (deleted in oneTBB 2021+),
replaced deprecated `cache_aligned_allocator::construct()/destroy()` with placement new /
explicit destructor.

**main.cpp** — replaced `tbb::task_scheduler_init` with `tbb::global_control` +
`tbb::info::default_concurrency()` (oneTBB 2021+ API).

## Usage

```
phase_limiter --mastering true --mastering_mode mastering5 \
  --reference -9 \
  --mastering5_mastering_level 0.8 \
  --input input.wav --output output.wav
```

Key flags:
- `--reference` — loudness target in LUFS (default -9; -12/-14 = less limiting artifacts)
- `--mastering5_mastering_level` — intensity 0–1
- `--ceiling` — true-peak ceiling dB (default 0; use -1.0 for headroom)
- `--pre_compression_threshold` — pre-comp threshold offset dB
- `--mastering5_eq_band_levels` — per-band wet-gain multipliers CSV (coming in FAZA 1)

Full flag list: `src/phase_limiter/main.cpp` (all `DEFINE_*` macros).
